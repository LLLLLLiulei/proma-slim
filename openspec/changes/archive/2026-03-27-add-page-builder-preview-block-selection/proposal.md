## Why

当前 `page-builder` 只能让用户通过自然语言笼统描述要修改的页面内容，用户很难明确指出“改这个区块”，尤其当页面结构变复杂后，沟通成本会快速上升。现在需要补上预览区块选择能力，让用户可以先从左侧页面中选中目标区块，再通过对话精确驱动下一次修改。

## What Changes

- 在 `page-builder` Builder 页右侧输入区增加一个可切换的选区入口按钮：默认显示“选择进行编辑”；进入选区准备态后显示“从页面中选择”；成功选中区块后显示“已选区域”；再次点击后回到默认态并清空选区。
- 为左侧 iframe 预览增加页面内选择桥接能力：进入选区模式后，鼠标 hover 可选区块时显示预高亮，点击后显示选中高亮；高亮框使用直角边框，并在左上角展示当前区块名称标签。桥接运行时代码通过服务端向 HTML 预览按需注入外部 JS 资源加载，不直接写入用户生成的网页文件。
- 将当前选中的区块仅作为“下一条消息”的隐藏上下文参与发送，向 Agent 注入区块 `selector` 与用户当前消息；消息发送成功后自动清除选中状态。
- 使选中状态仅在当前预览 DOM 生命周期内有效；当预览刷新、重载或退出选区模式时，高亮与选中状态一并失效，不做恢复。
- 保持现有 `page-builder` 双栏布局、共享对话框复用方式与预览自动刷新机制不变。

## Capabilities

### New Capabilities
- `page-builder-preview-block-selection`: 覆盖 Builder 页“从页面中选择”入口、预览区 hover/selected 高亮、iframe 与父页面通信、下一条消息消费后自动清除的区块选择能力。

### Modified Capabilities
- None.

## Impact

- 影响 `apps/page-builder` 的 Builder 页与预览面板组件，需要为 iframe 预览接入选择模式开关与选中态展示。
- 影响共享 `apps/app` 对话输入区接入方式，需要在 page-builder Builder 页向共享 `AgentView` 注入区块选择状态，并通过隐藏上下文装饰下一条消息。
- 可能影响工作区预览响应链路，需要为 `workspace-files` 预览页面注入轻量桥接加载器，并由其按需加载外部选择桥接脚本。
