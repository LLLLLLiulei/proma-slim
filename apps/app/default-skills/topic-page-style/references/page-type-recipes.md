# 传统中文专题页类型配方

> 查阅时机：在 `SKILL.md` 第三节确定页面类型后，读取本文件中对应的一节。它把参考截图中高频的整页骨架、栏目顺序、导航、标题和图文比例沉淀成可执行配方。

## 通用 CMS 骨架

传统 CMS 专题页优先使用“内容壳”而非全页交替 section：

```text
[全宽海报式 Banner：优先 .kv-banner / .hero--poster-image，保持整图不裁切]
[静态栏目导航条：传统 CMS 默认不 sticky]
<main class="topic-shell topic-shell--narrow 或默认 1040px">
  [module-box: 焦点/头条]
  [module-box: 栏目 A + 栏目 B，可用 M-twin]
  [module-box: 图集/视频/议程/嘉宾]
</main>
[footer]
```

模块之间靠 `module-box` 的细边框、栏目标题线、浅灰分割线和紧凑间距形成层次。只有纪实/榜单/深色科技类页面可使用更强的整段背景。

## 截图样本共性规则

这些规则来自传统中文专题页样本集，应作为默认风格底座：

- **满宽 Banner + 窄正文**：多数页面是满宽主题 Banner/KV，下方接居中正文壳。桌面正文壳通常控制在 `960-1100px`，少数会议或宽图集可到 `1120-1200px`。
- **Banner 是专题识别，不是普通背景图**：政务用红旗、金色纪念物、城市剪影；会议培训用蓝白波浪、抽象会务空间和培训场景；科技年会用深蓝星空/网络线；城市文旅用横向城市风景；公益/纪实用真实摄影；榜单用浅灰海报或斜切色块。AI 生成 Banner 只生成无文字视觉底图，标题、年份、单位、会务信息和 logo 均由 HTML/CSS 或用户提供素材处理。
- **导航贴紧 Banner**：传统专题默认横向导航条紧贴 Banner 下方，active 项用主题色实心块。只有深色科技页可用顶部小白字导航，公益纪实类可用竖排导航或无导航。
- **正文是 CMS 模块壳**：优先使用焦点图+新闻列表、缩略图列表、日期卡、三/四列图文、视频缩略图、议程表、嘉宾网格和图集；不要把整页做成现代大圆角营销卡片流。
- **信息密度高于现代 Landing**：新闻标题 15-18px，摘要 13-14px，条目之间用浅灰实线/虚线；区块间距约 20-40px。
- **圆角和阴影克制**：模块、图片默认直角或 0-2px；信息卡可 2-4px；圆形只用于嘉宾头像、播放按钮、时间轴节点。不要用 12px 以上大圆角和弥散阴影。
- **一页一个强主题色**：红金、蓝白、深蓝科技、青蓝城市、沙金经济、橙红节日等；正文阅读区保持白底/深灰字，主题色用于导航、栏目标题、分割线、日期牌和按钮。
- **移动端折叠**：Banner 保持满宽，导航横向滚动或两行；两栏、三栏、四栏逐级降为 2 列或 1 列；深色科技页移动端仍保持深色体系，不要改成白卡。

用户提供参考截图/链接时，先提取以上维度再匹配下面的类型配方。不要做像素级复刻，也不要把单张截图里的错误、过时内容或真实人物/机构硬事实照搬到新页面。

## 政务红金海报型

参考气质：建国 70 周年、京津冀协同发展。

```text
[红金全宽海报 Banner，地标/城市剪影，标题很大；有整图时用 .kv-banner]
[红色或深红静态导航条，可省略]
<topic-shell 1000-1080px>
  [module-box J: 左大图/视频 55% | 右头条列表 45%]
  [module-box M-twin: 高层论述 | 地方动态]
  [module-box E-asymmetric: 图说专题，大图 + 缩略图]
  [module-box F-cols4: 成果/主题卡片]
</topic-shell>
[简洁 footer]
```

默认规则：

- 标题用 `section-title--cms-line`、`.section-divider-logo` 或政务强栏目时用 `section-title--bar`/`.section-title--ribbon`。
- 图集和政务图片圆角 0-2px。
- 不要把每个模块做成独立大色块；红色主要用于 Banner、导航、标题条、分隔标识。

## 蓝白会议培训型

参考气质：会议议程、培训处业务专题模板。

```text
[蓝白会议无文字 KV 视觉底图；标题、年份、会议名、主办信息用 HTML/CSS 叠加]
[蓝色静态导航条，可加 .tab-nav--blue .tab-nav--block-active]
<topic-shell 960-1080px>
  [module-box J: 左视频或主图 58% | 右最新资讯/日期卡 42%]
  [module-box D: .agenda-panel + .agenda-tabs + .agenda-timeline，或普通议程表]
  [module-box F-cols4: 热点资讯卡片]
  [module-box E-asymmetric: 图片集锦，大图 + 右侧小图；仅在有真实会议照片或已生成主图时使用]
</topic-shell>
[蓝色 footer：.footer--multi + .footer__contact + .footer__qr + .footer__icp]
```

默认规则：

- 议程模块是中段核心，不要藏在普通卡片后。
- Tab 可使用 `.tab-nav--primary` 或 `.tab-nav--blue`，默认不要 sticky。
- 无真实图片时，不要直接删除视觉入口；先尝试使用可用的图片生成或图片搜索/下载工具补充 1 张主视觉图。确实没有可用视觉资产时，图集改用 `.gallery--asymmetric-compact`、普通 2x2 预留图、焦点占位、新闻列表或“会议图片持续更新”提示，不要堆出大面积伪图集。
- 页脚可用 `.footer--multi`，二维码用 `.footer__qr`，备案/版权行用 `.footer__icp`。

## 深色科技年会型

参考气质：中国软件产业年会。

```text
[深色科技背景，顶部小导航，中央大标题 + 英文副标题]
<topic-shell topic-shell--dark 960-1080px>
  [module-box module-box--dark A: 年会介绍]
  [module-box module-box--dark J: 左图 | 右资讯]
  [module-box module-box--dark F-guest: 嘉宾阵列]
  [module-box module-box--dark D: 深色描边议程表]
  [module-box module-box--dark E/F: 分享回顾/合作伙伴]
</topic-shell>
```

默认规则：

- 全页可用深色背景，但内容仍放入窄容器。
- 文字对比必须足够；不要使用低透明小字堆满深色背景。
- 合作伙伴 logo 放白底小卡片，避免深色背景吞掉 logo。

## 门户资讯聚合型

参考气质：地方两会、博览会、中国“互联网+”。

```text
[主题照片或城市/会场 Banner]
[静态栏目导航条]
<topic-shell 960-1080px>
  [module-box J1/J2: 焦点图文，左图右文或左列表右图]
  [module-box M-twin: 栏目 A 新闻列表 | 栏目 B 缩略图列表]
  [module-box F-cols3: 三列图文资讯]
  [module-box E-asymmetric 或 .video-grid: 高清图/视频]
</topic-shell>
[深色或浅灰 footer]
```

默认规则：

- 新闻列表和缩略图列表是核心，不要只做大卡片网格。
- 栏目标题优先 `section-title--cms-line` 或 `module-header` + “更多>”。
- 主内容壳宽度通常 960-1080px，不要默认 1200px。

## 城市文旅频道型

参考气质：千年惠州。

```text
[城市风景全宽 Banner，主题名可左对齐；整图 KV 优先]
[蓝色导航条，当前项整块红/深色高亮：`.tab-nav--blue.tab-nav--blue-red-active`]
<topic-shell 1000-1080px>
  [module-box: 头条横条]
  [module-box J: 左轮播/大图 | 右文化摘要]
  [module-box M-twin: 西湖文艺 | 非遗传承]
  [module-box F/.video-grid: 4x2 视频或活动卡]
  [module-box M: 左史说列表 | 右活动 banner]
</topic-shell>
[蓝色 footer]
```

默认规则：

- 图片密度高，视频/活动/文化栏目可多。
- 导航贴紧 Banner，当前项用整块底色而不是下划线。
- 标题可以用蓝色门户标题，整体比政务更明亮。

## 公益行动型

参考气质：光盘行动。

```text
[摄影 Hero，可竖排标题或少量文字覆盖]
<topic-shell 960-1080px>
  [module-box M-twin: 2x2 摘要新闻]
  [module-box: 主题大图 16:5 或 21:9]
  [module-box M: 左行动跟踪缩略图列表 | 右视频列表]
  [module-box M-twin: 校园行动 | 典型范例]
</topic-shell>
[灰色/深色 footer]
```

默认规则：

- 颜色克制，主要靠照片表达主题。
- 视频卡需要播放按钮遮罩。
- 文字列表可以紧凑，但大图之间要有呼吸感。

## 纪实节日叙事型

参考气质：向着家的方向骑行。

```text
[全宽纪实照片 Hero，左侧半透明文字面板]
<topic-shell 1080px>
  [module-box J/M: 左缩略图 + 中故事摘要 + 右大图]
  [module-box E/L: 横向五图带]
</topic-shell>
[全宽暖色活动区：`.festival-band` + `.wish-panel`，中央白色面板，左留言列表 | 右活动海报]
[深色 footer]
```

默认规则：

- 可以使用局部全宽色块，但内容仍居中。
- 大图优先，正文不要过密。
- 暖色节日区不应变成现代 CTA 大按钮。

## 榜单长条海报型

参考气质：中国体育产业风云榜。

```text
[极简 Header，标题偏右或倾斜，留白多]
[说明区：`.ranking-board` 黑板/公告牌]
[repeated band：`.ranking-band`]
  [大色块 + 图片主体 + 短列表 + 分类手写/大标题]
[footer]
```

默认规则：

- 每个 band 高度稳定，约 300-420px。
- 色块、斜切、物体/场景图是主视觉；文字只放短列表。斜切色带是本类型的局部例外，不要扩散到普通资讯/会议页。
- 不要把榜单做成普通 3 列卡片网格。
