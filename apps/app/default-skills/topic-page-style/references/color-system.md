# 配色系统参考

> 查阅时机：SKILL.md 第四节要求你在生成前内部确认"主色色相角度+明暗基调"。本文件提供推导这两个值的具体算法，以及几个方向参考。**方向参考是教你算法怎么用的例子，不是可以直接复制的答案**——真正生成时必须按当前主题重新计算数值，不能照抄下面任何一组 hex。

## 1. 变量清单（写入 CSS `:root`，完整声明见 `assets/base.css`）

| 变量 | 用途 |
|------|------|
| `--color-primary` | 主色（标题装饰、按钮、强调元素） |
| `--color-primary-dark` | 深色变体（悬停、Footer） |
| `--color-accent` | 点缀色（数字、装饰线、高亮圆点） |
| `--color-accent-light` | 浅色变体（标签背景） |
| `--color-bg` | 主背景色 |
| `--color-bg-alt` | 交替区块背景 |
| `--color-bg-dark` | 深色底（Footer、深色区块） |
| `--color-text` | 正文颜色 |
| `--color-text-secondary` | 次要文字 |
| `--color-border` | 边框和分割线 |

## 2. 推导算法（三步）

### 第一步：主题关键词 → 主色色相区间

不要直接取某个具体 hex，先确定一个**色相角度区间**，再在区间内选一个具体值（这样同类主题每次生成都能落在不同点上，而不是每次收敛到同一个 hex）：

| 主题关键词 | 色相区间（HSL Hue） | 说明 |
|---|---|---|
| 科技峰会/软件产业年会/数字经济专题 | 200–250°（蓝、青、靛） | 区间较宽，避免总落在 210° 附近的"安全蓝" |
| 自然/环保/农业/健康 | 90–150°（绿） | |
| 美食/餐饮/活力/促销 | 10–40°（橙、红） | |
| 商务/金融/咨询 | 210–240°（深蓝、藏青），明度降低 10-15% | 与科技区间有重叠，通过降低明度形成差异化 |
| 文化/艺术/历史 | 270–320°（紫）或 30–45°（金）或 340–355°（酒红） | 三选一，按主题细分 |
| 生活/美妆/女性 | 330–350°（玫红、粉） | |
| 极简/文档/工具 | 不用色相，黑白灰，靠明度层次区分 | |
| 节庆/赛事/热烈 | 0–10°（红）搭配 40–50°（金） | |

用户指定颜色时以用户指定为准，跳过本步。

### 第二步：在区间内选定具体色相后，派生其余角色

- `--color-primary-dark`：主色降明度 15–25%（同色相，仅调整 L）。
- `--color-accent`：主色色相 ±20–40°（邻近色）或 +150–180°（互补色），二选一，不要每次都用同一种关系。
- `--color-accent-light`：accent 大幅稀释（提高明度、降低饱和度，接近背景色）。
- `--color-bg-alt`：以主背景为基础，混入少量主色色相（HSL 模式下 S 取 5–15%、L 取主背景 L − 10~18%），**确保与主背景明度差 ≥ 10%**（即 HSL 中 L 值相差 ≥ 10 个百分点）。注意：主背景 L 越高（越白），需要降低的 L 越多才能达到 10% 差值——例如主背景 L=100% 时需至少降到 L=90%。深色主色时可能需要混入更多比例或用更亮的 tint，避免交替区块背景与白色主背景无法区分。
- `--color-bg-dark`：primary-dark 或近黑（`#1a1a1a` 附近，可按主色色相略微调整色调，不必是纯灰黑）。
- `--color-text-secondary`：浅底 ≥ `#666`，深底 ≥ `#9ca3af`（对比度硬底线，见第 4 节）。

### 第三步：明暗基调

- 浅色基调（默认）：`--color-bg: #fff` 附近。
- 深色基调：`--color-bg` 用深色（如 `#0a0e27` 附近），科技/数字类主题更适合。
- 同一页面**主体区**统一基调；CTA 和 Footer 允许用深色底作为视觉终点，不受主体基调限制。

## 3. 方向参考（用于理解算法，不可直接复用 hex）

以下 5 组是方向示例，**不是"可选模板"**。合理主题色相可以落在同一区间；禁止的是原样复制整组 hex 或机械套用同一套明暗/辅色关系。需要差异化时，优先调整饱和度、明度、辅色、标题条和导航处理，而不是为了避开某个 hue 数字而偏离主题。

- 暖红-金方向（会议、庆典）：色相约 0°(红) + 40°(金)，浅色基调。
- 蓝-商务方向（培训、机构、项目）：色相约 215°，浅色基调，明度偏低（更沉稳）。
- 深色-科技方向（科技峰会、数字论坛）：色相约 220°，深色基调。（与蓝-商务方向色相接近但因深色基调而视觉差异明显，选择时优先通过明暗基调区分，而非仅靠色相微调。）
- 暖橙-人文方向（文旅、公益、人文纪实）：色相约 20°，浅色暖白基调。
- 灰度-简约方向（极简、环保、公益）：不用色相，仅明度层次。

## 4. 配色硬规则（不可协商）

- 主色 + 强调色 ≤ 2 个高饱和色，其余靠明度/中性色区分层次。
- 不用纯黑 `#000` 做文字。
- 图片上叠加文字必须有遮罩，透明度 ≥ `rgba(0,0,0,0.4)`。
- 白底次要文字 ≥ `#666`；深底次要文字 ≥ `#9ca3af`——这是最低可读性要求，不是建议值。
- CTA 和 Footer 允许使用深色底色（`--color-bg-dark` 或 `--color-primary-dark`）作为页面视觉终点，不受主体基调限制。
