# Guided Briefing Thresholds

## 可稳定成稿阈值

提问方式不是固定问卷，但要遵守以下 contract：

- 必问项：页面目标、面向人群、主要内容块
- 条件必问项：风格方向、设备重点、必保留 / 必避免项、当前页面是继续迭代还是整页重做
- 强制确认项：生成前最终确认、非空页面整页覆盖确认

当以下信息已经明确，或已经可以安全使用合理默认值时，可以停止继续追问并进入生成前确认：

- 页面是做什么的
- 主要给谁看
- 最重要的内容块是什么
- 整体感觉或风格方向是什么
- 更偏手机还是电脑
- 是否存在必须出现或必须避免的内容

## 最终确认

进入生成前，先用简短摘要复述你的理解，再通过 `AskUserQuestion` 做最终确认。

确认摘要通常应包含：

- 页面目标
- 面向人群
- 主要内容块
- 风格方向
- 设备重点
- 必保留 / 必避免项

## “你帮我决定”

如果用户明确说“你帮我决定”或同等含义：

- 仍然不要跳过最终确认
- 只对非关键细节使用合理默认值
- 不要替用户编造强事实信息

## 非空页面整页覆盖

如果当前页面已经存在非平凡内容，而用户想整页重做：

- 先做整页覆盖确认
- 未确认前不要直接整页重写
